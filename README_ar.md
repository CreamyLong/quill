Quill هو إطار عمل وكيل خارق مفتوح المصدر. مع تنسيق الوكلاء الفرعيين، والتنفيذ في بيئة معزولة، ونظام مهارات قابل للتوسيع، يساعدك في إنجاز أعمال متعددة الوسائط — البحث، البرمجة، تحليل البيانات، إنشاء المستندات، والمزيد.

---

## 📸 عرض الميزات

### 🔬 البحث العميق
بحث متعدد المصادر مع التحقق المتبادل والتقارير المقتبسة. يقوم Quill بتنسيق عدة وكلاء فرعيين لاستكشاف المواضيع بعمق.

### 💻 تنفيذ التعليمات البرمجية
قم بتشغيل Python / Bash / عمليات الملفات بأمان في بيئة معزولة.

### 🤖 تعالو الوكلاء الفرعيين
الوكيل الرئيسي يرسل وكلاء فرعيين متخصصين للمهام المعقدة بالتوازي.

### 🧩 المهارات والإضافات القابلة للتوسيع
قم بتثبيت المهارات لتوسيع القدرات. أنشئ إضافات مخصصة مع خطافات دورة الحياة.

### 🧠 الذاكرة طويلة المدى
يسجل باستمرار ملف المستخدم وسجل المحادثات مع سياسات الإخلاء القائمة على الثقة.

### 🌐 متعدد النماذج ومتعدد اللغات
DeepSeek / OpenAI / Anthropic / vLLM / Ollama والمزيد. الواجهة تدعم 8 لغات.

## 🚀 البدء السريع

### المتطلبات المسبقة

- Node.js 22+ / pnpm 10+
- Python 3.12+ (اختياري، للتنفيذ في البيئة المعزولة)

### التطوير المحلي

```bash
git clone https://github.com/<your-org>/quill.git
cd quill
make setup        # معالج تفاعلي، يكتمل في حوالي دقيقتين
make dev          # بدء الخدمات، افتح http://localhost:2126
```

### نشر Docker

```bash
docker compose up -d
```
